# Core

- Verify before use: never invent files, classes, routes, endpoints, JSON fields, translation keys or package APIs. Open the source first.
- When docs and code disagree, follow the code and report the mismatch.
- Change only what the task asks. No unrelated refactors or formatting.
- Report exact commands and results; an unrun check is "not run".
- Read `.agent-team.yaml` and `docs/agent-context.md` before starting; follow the profile's architecture, state and storage only.
- Copy the reference feature named in `docs/agent-context.md`; never copy the known deviations listed there.
- Code, identifiers, commits and docs are in English; talk to the user in their language.
