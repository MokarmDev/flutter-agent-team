# Flutter Agent Team

## Install

In Cursor: Settings, Plugins, Import from Repo, then enter `https://github.com/MokarmDev/flutter-agent-team`.

A team of Flutter AI agents (product, architecture, UI, data, QA, review, debugging) with skills, rules and guard hooks that adapt to your project's architecture and state management.

It ships 7 agents (product-manager, architect, flutter-developer, data-integrator, qa-engineer, code-reviewer, bug-investigator), workflow commands such as /agent-team-init, /ticket-new, /ticket-start, /ticket-build, /review and /ticket-ship, skills for Clean Architecture, MVVM, BLoC, networking, local storage, localization and testing, and guard hooks that block edits to generated files, reads of secret files and destructive shell commands.

Run /agent-team-init in your Flutter project after installing. Full documentation: https://github.com/MokarmDev/flutter-agent-team

This folder is generated by `node tool/build.mjs` from `src/`; do not edit it by hand.
