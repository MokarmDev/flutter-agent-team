# Ticket linking

- Work starts from a ticket ID (or `/quick` for small changes).
- Branch: `branch_pattern` from `.agent-team.yaml`, for example `feat/T-012-order-list`.
- Commits: Conventional Commits with the ticket ID (`Refs: T-012`).
- PR body links the ticket; plans and reports use the ticket ID in their file names.
